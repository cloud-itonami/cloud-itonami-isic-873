HARD hold 一覧（6 件 · override 不可）

governor の 3 つの HARD チェックによる拒否。人間の承認でも覆せず、承認画面にすら到達しない。段階ロールアウトによる hold は違反を伴わないため、ここには現れない。
この実行が実際に発火させた規則: effect-not-propose、op-not-allowed、resident-unverified、scope-excluded（4/4）。件数ではなく網羅が生成条件で、未発火の規則が 1 つでもあれば -main は書き込みを拒否して失敗する。

所見 · coordinate-supply-request は自分自身の但し書きで恒久的に HARD hold される

この op は closed allowlist の一員だが、advisor が生成する定型文が governor の scope 除外語彙に一致するため、内容にかかわらず commit できない。一致した語: 薬（:rationale 内）

該当箇所: 「布製品・移動補助具・食料品などの非医薬品消耗品の調達調整のみ。投薬なし。」 — これは投薬がないことを述べた否定文だが、部分文字列走査は肯定的な言及と区別できない。走査が否定を扱えるようになるか語彙が変われば、この所見は次回生成時に自動的に消える。

所見 · 承認者は :payload にしか残らない

store は record 全体を保持するので承認者は失われていない（t1, t6）。ただし承認者が入るのは :payload だけで、:value は承認前の草案のままである。:value だけを読む下流の利用者は、承認された record を承認者なしと読む。
